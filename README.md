# Read this first

This download contains **only Markdown files**. There is no application, database, required service, or build step. Open [index.md](index.md) in a Markdown reader, or load the folder into an LLM retrieval system. Keep the directory structure intact so relative links continue to work.

## What is included

The [profile directory](styles/index.md) contains 153 independently readable articles. Each carries structured metadata, aliases where supported, geographical focus, scope, source references, and comparison links. Factual descriptions use footnotes keyed to the metadata's source identifiers.

The [navigation directory](navigation/index.md) offers names, regions, families, and historical scope. The [editorial directory](editorial/index.md) explains evidence handling, boundaries, and known gaps. The [reference directory](references/index.md) lists the sources actually used by the profiles.

## Reading a profile

Start with the opening definition, then read its character, brewing, and historical sections. Read the evidence note before treating the description as universal. Follow the source footnotes for the underlying account, and the comparison links for nearby concepts.

Do not mistake a modern judging category for an ancient identity. Likewise, a laboratory study of a few batches does not describe every community's practice. Profiles with limited or abstract-only evidence say so.
