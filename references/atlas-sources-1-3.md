# Additional research sources: edition 1.3

**Consultation date: 27 October 2026.** Source access is specific to each cited page. Previously published research, authoritative institutions, publisher abstracts and technical summaries are not interchangeable forms of evidence. An external URL is not proof that every page of a publication was inspected. The references below have the access limitations stated with each source; source IDs connect back to the new subject articles and extensions.

## Keeping the register honest

This supplement contains 45 distinct source IDs for this expansion, **not** 45 newly published studies. Some sources were already cited in earlier editions and are explicitly reused. Original articles’ metadata contains the exact source IDs and claim footnotes. Studies consulted only as an abstract or publisher description are not used to supply specific methods absent from that excerpt. New cultural work still needs independent source-language and community review.
