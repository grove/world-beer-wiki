# Processes: follow the transformation

A process explains what happens to a material. It does not, by itself, identify a regional tradition, a particular organism or a finished beer style.

| Process | The useful question |
|---|---|
| [Starch conversion](starch-conversion.md) | Where do fermentable sugars come from? |
| [Raw ale](raw-ale.md) | Which heating step is absent, and which steps still happen? |
| [Baked mash](baked-mash.md) | What is baked: malt, bread, mash or finished beer? |
| [Decoction](decoction.md) | What is heated separately, and why distinguish mash from wort? |
| [Kettle souring](kettle-souring.md) | When does acidification happen relative to alcoholic fermentation? |
| [Spontaneous fermentation](spontaneous-fermentation.md) | How is fermentation established, and what happens afterward? |
| [Blending and bottle conditioning](blending-and-bottle-conditioning.md) | Which operation selects the mixture, and which develops carbonation? |
| [Dry hopping and hop creep](dry-hopping-and-hop-creep.md) | Can an aroma addition change fermentability too? |

These are explanations, not complete recipes or validated food-production procedures. Read the [ingredient directory](../ingredients/index.md), [microbial atlas](../microbiology/index.md) and [objects](../objects/index.md) alongside them.
