# Munkoyo root-based saccharification versus malting

The problem is straightforward: **yeast ferments available sugars, not unconverted cereal starch**. Many brewing traditions solve that problem in different ways. A published 1997 munkoyo experiment studied cooked maize meal combined with enzyme-bearing *Rhynchosia* root extract, demonstrating a documented route that does not start with barley malt.[^v16-munkoyo]

## Input, transformation, outcome

Cooked maize provides starch; the tested root extract contributes amylase activity; microbes can then act on available carbohydrates. Zulu, Dillon and Owens studied a particular preparation with selected *Lactobacillus confusus* and *Saccharomyces cerevisiae* strains. Those chosen organisms explain the **laboratory design**, not every customary Zambian starter community.[^v16-munkoyo]

## Three pathways to compare

Malted barley uses enzymes developed during grain germination. Some Asian starter cakes support starch breakdown through mold-associated enzyme systems. The Rhynchosia example uses plant-derived enzymes described in the munkoyo study. Each pathway needs its own process conditions, evidence and cultural setting; sharing a chemical function does not imply shared ancestry.

## Evidence boundary

An indexed primary-study abstract supports the identified experiment. It does not specify a universal recipe, safe wild-plant identification or measured enzymatic behavior for every root product.
